# Install Clear Reply

Download **clear-reply.zip** from [Releases](https://github.com/arunkarthik-n/clear-reply/releases/latest). Do not use the **Source code** zip.

1. [Download clear-reply.zip](https://github.com/arunkarthik-n/clear-reply/releases/latest/download/clear-reply.zip).
2. Unzip it. The folder must contain `manifest.json`.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select **that folder** (the one with `manifest.json`).
6. Open **Clear Reply → Settings**, enter your Groq API key, and click **Save**.

If Chrome says the manifest is missing, you selected the parent folder or downloaded source instead of `clear-reply.zip`.

Chrome requires Developer mode for extensions installed outside the Chrome Web Store.
